# Pilot report — 2026-09-04

This report summarizes protocol `0.1` across the 30 targets declared in [`sample/targets.csv`](../sample/targets.csv). It describes a purposive technology-heavy sample, not the whole web.

## Executive result

Seven targets exposed a plausible root `llms.txt`. Only two landing pages advertised a Markdown alternate, and none advertised `rel="describedby"`. The new discovery mechanisms were therefore much less visible than root-file publication in this pilot.

| Category | Targets | Landing HTTP 200 | Plausible root `llms.txt` | Markdown alternate on landing |
|---|---:|---:|---:|---:|
| AI labs | 5 | 5 | 1 | 0 |
| Cloud and deployment | 5 | 5 | 4 | 2 |
| Developer platforms | 7 | 4 | 1 | 0 |
| Language and documentation | 8 | 8 | 1 | 0 |
| Standards and publishing | 5 | 5 | 0 | 0 |
| **Total** | **30** | **27** | **7** | **2** |

## Discovery signals

Cloudflare advertised [`https://www.cloudflare.com/.md`](https://www.cloudflare.com/.md) and Netlify advertised [`https://www.netlify.com/index.md`](https://www.netlify.com/index.md) as `rel="alternate"` with `type="text/markdown"`.

No target landing page exposed `rel="describedby"`. No landing response included `Content-Signal` or `X-Robots-Tag`. These are exact landing-page observations; path-scoped documentation elsewhere on a site can differ.

## Request and policy outcomes

- `27/30` landing requests returned HTTP `200`.
- `crates.io` returned `404` for its declared root URL.
- `npmjs.com` and `stackoverflow.com` returned `403` to the identified collector.
- `27/30` robots requests returned HTTP `200`; the remaining statuses were one each of `403`, `404`, and `418`.
- Among the available robots responses, Protego did not classify the exact landing root as disallowed for `GPTBot`, `ClaudeBot`, `Google-Extended`, or `CCBot`. This says nothing about rules on deeper paths.

Blocked and non-`200` targets remain in the denominator because accessibility to an identified lightweight client is itself part of the reproducibility record. They are not counted as evidence that a signal is absent.

## What the pilot supports

The snapshot supports three narrow observations:

1. root `llms.txt` publication was present but not dominant in this selected sample;
2. explicit v2-style discovery from landing pages was rarer than root-file publication;
3. adoption was concentrated in the cloud category within this sample.

It does not support claims about overall adoption, crawler compliance, permission to train, or the behavior of any named company.

## Next falsifiable step

The next release should repeat the same 30-target snapshot without changing the protocol, then add a separate path-scoped experiment. A useful trend claim requires at least two comparable dates; a useful v2 conformance claim requires fetching only explicitly discovered links and validating their relation to the declaring page.
